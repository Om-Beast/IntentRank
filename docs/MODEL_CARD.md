# IntentRank model card

## Intended use

An independent educational and research project for understanding e-commerce search relevance on the public Wayfair WANDS snapshot. It is not a Wayfair production service and has no affiliation with Wayfair.

## System

BM25 and frozen `all-MiniLM-L6-v2` retrieve up to 100 products each from 42,994 catalogue items. A LambdaMART reranker scores their union using 18 features. The MiniLM encoder is pretrained, quantized, and **not fine-tuned here**. The supervised component trained by this project is the gradient-boosted reranker.

Product text is assembled from the name, class, description, and structured features. Dense input uses name, class, and the first 500 description characters, truncated at 128 subword tokens. BM25 uses a longer body with name repeated twice. Descriptions and features are capped at 1,800 and 4,000 characters when the runtime catalogue is built. Attribute evidence is string-based, can include multiple product variants, and must not be treated as verified specifications.

## Data and splitting

WANDS has 480 queries, 42,994 products, and 233,448 human query-product relevance labels. Exact maps to grade 2, Partial to grade 1, and Irrelevant to grade 0. NDCG gain is `2^grade - 1`.

Queries form connected groups when normalized token Jaccard is at least 0.75 or normalized string similarity is at least 0.88. Entire groups are assigned to training, validation, or test using seed 42 and approximate 70/15/15 targets. The actual IDs and counts are committed in `artifacts/splits.json` and `artifacts/training.json`. No query ID occurs in more than one partition. Query families are heuristic; they may miss semantic paraphrases.

All catalogue products appear in the retrieval index, including products judged against test queries. This is intentional new-query evaluation. It is not product-held-out or temporal evaluation. Judgments from training queries alone fit the ranker. Validation NDCG@10 selects the number of boosting iterations. Test labels are not used for feature selection, fitting, or early stopping.

## Evaluation

See `artifacts/evaluation.json` for actual aggregate and per-query results, bootstrap intervals, and local CPU latency. The primary metric is judged-pool NDCG@10, ranking all annotated products for each test query. This isolates reranking quality in a fully judged candidate set and is not a full-catalogue retrieval metric.

The report separately measures full-catalogue NDCG@10, known-positive Recall@100, candidate recall, and judgment coverage at 10. Unjudged retrieved products receive zero gain for full-catalogue NDCG. Incompleteness can penalize relevant unjudged products, so the metric must be read with judgment coverage. Recall positives include Exact and Partial labels. A union of two top-100 lists can contain up to 200 candidates.

Latency includes uncached query encoding and ranking on the local CPU. It excludes network and process/model startup. These measurements do not establish production p95. Ranking scores are not calibrated probabilities. Feature gain importance is not causal attribution.

## Limitations

- The source has only 480 queries, so uncertainty remains meaningful even with hundreds of thousands of labels.
- The catalogue and judgments are static snapshots and may not reflect current inventory or user preferences.
- MiniLM may miss dimensions, negation, rare brand names, or fine-grained style constraints.
- Text can contain several product variants, conflicting attributes, and noisy descriptions. Attribute hints are evidence, not hard filters.
- Category filters apply to retrieved candidates in learned/hybrid mode, not a separate category-specific search index; recall can decrease.
- Reranking cannot recover a product that neither retriever selected.
- No personalization, commercial inventory feed, purchase flow, online experimentation, conversion study, or revenue impact is implemented.
- Product photographs and prices are absent from WANDS. The interface uses clearly labeled original category illustrations and never fabricates commercial metadata.
